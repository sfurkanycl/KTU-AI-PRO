# Korunan Windows modülleri

Bu dosyalar kullanıcının verdiği OgrenmeMolasi-Windows.zip içindeki EXE'nin
PYZ arşivinden, uygulama çalıştırılmadan çıkarılan Python 3.12 kod nesneleridir.
İş mantığı yeniden tahmin edilmemiştir; standart pyc başlığı eklenerek korunmuştur.
Kaynak .py dosyaları teslim edilmediğinden bunlar kaynak kod sayılmaz.
Kök klasördeki .py adaptörleri bunları yükler ve ek özellikleri bağlar.
Güncellemek için orijinal proje kaynakları tercih edilmelidir. Python 3.12 gerekir.
